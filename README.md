# 景行智调 · 本地视觉与 B 方案交付版

南京钟山风景区接驳车科研情景仿真，Python 3.12 + Streamlit。默认打开 User 游客端，Admin 登录后保留原调度功能。本系统没有接入景区真实实时运营数据。

## 本次交付

- User：自然景区照片、原始线路图、线路查询、回放与趋势布局，以及已发布三策略结果的只读展示。
- Admin：七个管理页面及登录页的统一视觉；原三策略计算完成后连同单次结果发布可核对的比较元数据。
- 资源：7 个项目内图片文件，约 1.12 MiB；6 张景区照片 + 1 张原始线路图。引用由项目位置解析，不依赖本机绝对路径或外部图片链接。缺图时显示提示并继续查询与仿真。
- B 方案：比较结果与本次单次运行放在同一原子更新 ZIP 中。记录场景、种子、客流签名、比较编号、三条运行编号、策略及关键指标；游客刷新后读取已发布快照。四份 CSV 格式与核心算法保持原样。

## 本地启动

在解压后的项目根目录打开终端：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

游客不需要管理员凭据。管理员凭据使用原有 Secrets 或环境变量配置；源码包不包含真实密码或 Secrets。未配置凭据时管理端关闭。详见本地运行说明。
