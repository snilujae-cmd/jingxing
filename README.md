# 景行智调 · 游客端优化候选版

南京钟山风景区接驳车科研情景仿真，Python 3.12 + Streamlit。默认打开 User 游客端，Admin 登录后保留原调度功能。本系统没有接入景区真实实时运营数据。

## 本次交付

- User：保留景区照片、原始线路图、线路查询、仿真回放、候车参考，以及单次有效仿真结果的站点排队趋势；游客页面不展示三策略比较和管理指标图表。
- Admin：保留七个管理页面、登录与访问控制、仿真运行、三策略比较和实验分析；原比较结果的发布及核对机制继续保留。
- 资源：7 个项目内图片文件，约 1.12 MiB；6 张景区照片 + 1 张原始线路图。引用由项目位置解析，不依赖本机绝对路径或外部图片链接。缺图时显示提示并继续查询与仿真。
- 共享结果：原 B 方案的比较元数据与单次运行仍存于同一原子更新 ZIP，供 Admin 核对；User 仅读取当前有效单次结果及其站点排队趋势。四份 CSV 格式与核心算法保持原样。

## 本地启动

在解压后的项目根目录打开终端：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

游客不需要管理员凭据。管理员凭据使用原有 Secrets 或环境变量配置；源码包不包含真实密码或 Secrets。未配置凭据时管理端关闭。详见本地运行说明。

## 基线与更新边界

本次以用户提供的 `jingxing-main.zip` 为源码基线，在独立目录实施。该压缩包是否与远端 `main` 及 Streamlit Cloud 当前运行版本逐字节一致，仍需部署负责人核对。

本包供本地审阅和团队整合：没有推送 GitHub、没有改动 `main`、没有更新公网应用。正式整合时先比较远端已有改动；不要直接覆盖最新仓库。源码 ZIP 不包含 `.git`、虚拟环境、缓存、运行时共享结果或真实 Secrets。

## 演示前检查

管理员在同一应用实例运行并发布有效结果，在 Admin 端核对三策略比较；独立游客选择“最新共享仿真”并刷新，核对单次运行对应的站点排队趋势。默认本地共享文件在实例重启后可能丢失，演示前需重新发布；不承诺跨实例或长期保存。本轮已完成的测试与尚未验证的项目见[游客端精简交付与回退](docs/游客端精简交付与回退_20261020.md)，不以旧报告替代。
