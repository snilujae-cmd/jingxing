# 景行智调｜Streamlit Community Cloud 测试部署

本目录是带 Admin 登录保护的整合版本，`app.py` 是唯一应用入口。游客默认进入 User 页面；管理员凭据只从 Streamlit Secrets 或进程环境读取。本目录不含真实凭据。

## 上传与部署

1. 将**本目录内的文件**放到一个由项目组控制的 GitHub 仓库根目录，保留 `.streamlit/config.toml`、`.gitignore`、`data/` 和 `views/` 的目录结构。不要把外层 `outputs/` 目录或旧版 ZIP 一起上传。
2. 仓库管理员用已连接 GitHub 的 Streamlit Community Cloud 账号创建应用，选择仓库、分支和入口文件 `app.py`；私有或组织仓库按平台提示完成额外授权。选择 Python 3.12，以便与本地报告的 Python 3.12 环境接近。依赖由根目录 `requirements.txt` 安装。
3. 在该应用的 **Secrets** 设置中，由账号持有人填写下面的 TOML，换成团队自行保管的真实值，然后保存并重新运行应用。不要把真实值写入代码、GitHub、工单或聊天记录。

   ```toml
   [admin]
   username = "<自行设置的管理员账号>"
   password = "<自行设置的强密码>"
   ```

4. 若要验证**未登录平台的游客**能直接访问，在应用的 Sharing 设置中将该测试应用设为公开。私有 GitHub 仓库创建的应用默认也是私有的；仓库本身可以继续保持私有。
5. 保存应用地址。需要协助线上验收时，只分享应用地址；管理员可在自己的浏览器完成凭据输入和管理操作。

如果尚无 GitHub 仓库或平台授权，先由仓库/平台账号持有人完成上述步骤。当前交付包本身不能替代 GitHub 授权，也不会自动创建线上应用。

## 线上烟测记录

每一项记录「通过 / 失败 / 未验证」及时间，不要用单元测试结果代替网页检查。

| 检查项 | 操作与期望 | 当前状态 |
| --- | --- | --- |
| 游客首页 | 全新无痕窗口打开应用地址，直接进入游客页面并能看演示数据。 | 未验证 |
| 未登录 Admin | 在无痕窗口直接输入一个 Admin 页面路径，管理内容不可见、管理操作不可运行。 | 未验证 |
| 错误密码 | 打开「管理员登录 / 退出」，使用错误密码，登录被拒。 | 未验证 |
| 正确登录与退出 | 管理员使用 Secrets 中的账号密码登录，可打开 Admin 页面；退出后再访问管理路径仍被拒。 | 未验证 |
| 仿真及发布 | 登录后在「客流场景」设参数，到「智能调度」运行；记录页面显示的运行编号，确认发布无报错。 | 未验证 |
| 跨浏览器读取 | 保持应用运行，在另一个浏览器或无痕窗口的游客页面选择「最新共享仿真」并刷新，核对同一个运行编号。 | 未验证 |

Admin 页面地址应从**已登录应用的地址栏**复制，再放到无痕窗口测试；不要猜测页面路径。若应用重启后共享结果消失，记录为持久性限制而不是成功的跨重启共享。

## 测试部署的范围

最新共享结果默认写到应用本地 `data/shared/current_run.zip`，用于同一运行实例的跨浏览器验收。Streamlit Community Cloud 的本地文件不适合作为长期持久存储；应用重启或实例变化后须重新运行和发布。多实例、长期保存和历史版本需要后续接入统一存储。

已有报告是在 Windows 沙箱中用 Python 3.12.14、Streamlit 1.66.0 运行的 **35 项单元测试通过**。本交付包的 `requirements.txt` 固定了本次复核使用的 Streamlit、Plotly、NumPy、Pandas、Graphviz 版本；复核这份交付包时，35 项测试也全部通过。该结果不代表云端页面已验收；此前 AppTest、本地真实浏览器和线上烟测均未完成。
