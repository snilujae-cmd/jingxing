### Admin 与共享层依赖

- 所有 Admin 页面继续依赖原 `admin_auth.py` 的页面保护；入口继续使用原账号验证和退出逻辑。
- `views/4_Admin_Smart_Dispatch.py` 的新增发布流程依赖 `comparison_data.py` 与 `shared_run_store.py`；三策略仍调用原 `core/simulation.py`，原导出依赖 `core/exporter.py`。

- 新安装不自带共享运行结果。管理员完成仿真并成功发布后，独立游客再刷新读取；默认路径位于项目内运行时目录 `data/shared/`。
