## 5. 本地运行与部署交接

1. 将最终 ZIP 解压到**新目录**，在项目根目录使用 Python 3.12 或更新版本，执行 `python -m pip install -r requirements.txt`、`python -m streamlit run app.py`。根网址进入门户，游客不需账号。
2. 管理员账号继续使用原 Streamlit Secrets `[admin]` 的 `username`、`password`，或环境变量 `JINGXING_ADMIN_USERNAME`、`JINGXING_ADMIN_PASSWORD`。不要把凭据写进源码、ZIP、截图或报告。未配置时管理端按原认证模块关闭。
3. 默认共享结果为运行实例的 `data/shared/current_run.zip`；发布同组比较时共用这一包。部署方需确认目录可写、持久化策略以及多实例是否使用共同存储。替换部署前先备份已有共享结果，不能把本地 QA 的共享 ZIP 复制到线上。
4. 在独立分支或预发布环境先对照当前远端提交与线上入口 `app.py`，处理差异后按第 3 节重测桌面、手机、管理权限与双端同组数据。由项目负责人确认素材权利、Secrets 和结果存储后，再决定是否合并与部署。本次交付本身没有执行线上更新。
