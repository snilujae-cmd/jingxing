## 3. 安装与启动

先安装 Python 3.12；安装后在“终端 / PowerShell”进入解压后的项目根目录。以下命令使用项目内虚拟环境，无需执行激活脚本：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

若 `py` 不可用，可用安装好的 Python 3.12 完整路径替代第一行的 `py -3.12`。看到本地浏览器地址后打开它。关闭本地服务时，在运行它的终端按 `Ctrl+C`。继续启动时只需最后一行。

本次沿用现有 `requirements.txt`，未新增运行依赖。请使用文件中的固定版本；如安装失败，保留完整错误供整合负责人核查，避免自行降低依赖版本。不要从 `views/user.py` 启动正式整合应用。

## 4. 本地管理员验证

未配置管理员时，游客功能可使用，管理端按既有机制关闭。交付包不提供测试账号文件，也不携带可登录的预设密码。

需要验收 Admin 时，测试者可在启动服务的同一个 PowerShell 中临时设置两项进程环境变量，再启动应用。将尖括号内容换成自己临时设置的测试值：

```powershell
$env:JINGXING_ADMIN_USERNAME = "<自设的本地测试账号>"
$env:JINGXING_ADMIN_PASSWORD = "<自设的本地临时密码>"
.\.venv\Scripts\python.exe -m streamlit run app.py
```

这些测试值只用于本地。不要输入或复制生产 Secrets，不要保存到源文件、截图或交付包。若计算机上已有 `.streamlit/secrets.toml` 的完整 `[admin]` 配置，既有鉴权会优先使用它；请在新解压目录测试，避免继承旧文件。验收结束并停止服务后，可关闭该终端，或清除上述环境变量：

```powershell
Remove-Item Env:JINGXING_ADMIN_USERNAME -ErrorAction SilentlyContinue
Remove-Item Env:JINGXING_ADMIN_PASSWORD -ErrorAction SilentlyContinue
```

## 5. 运行测试并验收界面

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试运行期间产生临时文件属于正常现象；正常清理后不应作为源码上传。执行结果及浏览器检查应记录在本次验收报告中，分别写“通过 / 失败 / 未验证”。本地通过不代表公网部署已通过。

浏览器检查建议按以下顺序进行，记录运行编号和比较编号：

1. 用全新无痕窗口打开应用，默认进入 User；检查主视觉、线路图原比例及原图查看、线路查询、回放和趋势分析。
2. 直接访问一条已登录时复制的 Admin 页面地址，确认未登录时无法看到管理内容；验证错误密码、正确登录、全部管理页导航及退出后再次直接访问。
3. 在“客流场景”设定并保存场景，到“智能调度”核对读取的场景，运行单次仿真；记录运行编号，确认四 CSV 导出仍可使用。
4. 运行同场景三策略比较，记录场景参数、客流签名、比较编号和三项运行编号；确认共享写入没有错误提示。
5. 在独立无痕游客窗口选择“最新共享仿真”，点击刷新，核对运行编号、比较编号、三策略名称与关键指标；游客端仅展示结果，不能进行后台调度或发布。
6. Admin 再运行一次单次策略，游客刷新后应读取新单次结果，并提示没有当前三策略比较，避免显示上一次比较。
7. 仅在另一份临时验收副本中暂时移走某张图片，再刷新对应页面；应出现说明性降级提示，查询及数据功能仍可继续。测试后放回原文件。
8. 在约 390px 宽度及桌面窗口查看按钮、卡片、表格和地图；检查照片无拉伸、图例无明显遮挡。移动端可横向滚动表格，不应被迫缩小线路图文字。

三策略使用同一仿真引擎、场景、随机种子、客流签名和车队配置。共享 ZIP 中的原四 CSV 结构保持不变，额外的 `comparison.json` 保存三策略参数与指标。单次导出按钮仍导出原四 CSV；它不会自动附带全组三策略结果。

## 6. 图片与运行数据注意事项

页面素材随源码位于 `assets/`，由项目内路径读取，不依赖原照片 ZIP、本机桌面目录或外部网页图片 URL。图片来源及待确认授权状态记录在 `assets/manifest.json`。保留水印及来源说明；正式公开使用前由团队确认再发布权限。地点未确认的照片不作具名景点图使用。

最新共享结果默认写入 `data/shared/current_run.zip`，运行时创建；`.gitignore` 已忽略该目录。新解压项目没有共享包时，游客仍可使用内置演示样例；管理员运行并成功发布后，独立游客可刷新读取。Cloud 重启、休眠恢复或实例变化后的本地文件保留不能作为长期存储承诺；演示前请重新发布并核对编号。
